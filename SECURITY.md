# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities **privately** via
[GitHub Private Vulnerability Reporting](https://github.com/OG-Open-Source/UserScripts/security/advisories/new).

Security vulnerabilities **MUST NOT** be reported in public issues.

When reporting, please include:

- The affected script and its version (or release tag, e.g. `h1dl-v1.1.0`).
- The browser, userscript manager, and their versions.
- A minimal description or reproduction of the vulnerability.

## Scope and Response Expectations

Only the latest released versions of each script are considered for security
fixes.

Reporting a vulnerability does not create any obligation for maintainers to
provide a fix within a specific timeframe. All software in this repository is
provided strictly "AS IS", without warranty of any kind — see the
[ISC License](LICENSE) for details.
